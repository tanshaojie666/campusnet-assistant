## 截图时的注意事项（重要）

截图会公开发布，**提交前必须打码/裁掉**下面这些内容：

- 学号、工号、姓名、手机号；
- 拨号账号与密码输入框里的内容；
- Wi-Fi SSID（可能包含宿舍号/楼栋名）；
- 代理客户端的**节点名、订阅地址、机场名称、剩余流量**；
- 日志窗口里的上述任何信息（日志比界面更容易泄露信息，**优先用 `--scan` / `--selftest` 的输出并手工删减**）。

技巧：截图前先断开或用一个测试账号；用 Windows 自带的"截图工具"框选，只保留控件区域；打码用不透明色块而不是模糊（模糊可能被还原）。
