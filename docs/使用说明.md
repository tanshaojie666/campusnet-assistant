# 校园网助手 · 完整使用说明

> 这份说明假设你**完全不懂网络**。每个功能都写了"它干嘛用、什么时候需要、怎么开"。
> 看不懂的地方直接跳过，只看你需要的部分就行。

---

## 一、这个软件是干嘛的

一句话：**它帮你自动连校园网，并且在你需要翻墙的时候自动帮你翻墙。**

具体来说，它替你做这四件事：

| 它做的事 | 好处 |
| --- | --- |
| **自动连校园网** | 开机、锁屏、甚至还没登录进桌面，它就把校园网连上（有线拨号、无线都行），掉线了自动重连 |
| **连校园网时自动关掉代理/VPN** | 很多校园网开着代理就拨不上号、或者认证失败，它会在拨号前帮你把代理关掉 |
| **需要翻墙时自动开代理** | 你打开浏览器/Telegram 这类程序，它自动开你的代理软件、挑一个能用的美国节点、并设好系统代理 |
| **绝不乱翻墙** | 连着校园网时**一定不翻墙**；连着手机热点/别的网时才翻墙 |

**它不会做的事**（免得你误会）：
- 它不提供翻墙服务，也不送节点 —— 用的是你自己买的机场/客户端。
- 它不碰你的账号密码以外的隐私，也不往任何服务器上传东西（所有事都在你电脑上做）。

## 二、怎么打开

| 你拿到的是 | 怎么开 |
| --- | --- |
| **免安装版**（包里带 `python` 文件夹） | 解压后双击 **`① 启动校园网助手.cmd`**，不用装任何东西 |
| **源码版**（只有代码） | 电脑上要有 Python 3.9+，双击 `CampusNetAssistant.pyw` |

> ⚠️ 免安装版**必须先解压再用**，不要在压缩包里直接双击。
> 如果 Windows 提示"未知发布者"，点「仍要运行」即可（这是自己写的程序，没有买数字签名）。

打开后窗口上方有三个分页：**状态**、**校园网**、**翻墙模式**。

---

## 三、第一次用（照着做，2 分钟）

1. 打开程序，切到 **「校园网」** 页
2. 「接入方式」选一个：
   - 宿舍插网线上网 → **有线**
   - 主要连学校 Wi-Fi → **无线**，下面填 Wi-Fi 名字
   - 两个都用 → **两者都要**
3. 「有线怎么认证」勾选（不知道怎么选就看下面第五节）
4. 填「账号」「密码」= 你平时登录校园网的账号密码
5. 点 **「保存设置」**，再点 **「立即连接」**
6. 切到「状态」页：变成绿色 **「已联网」** 就成了

想让它开机就工作：双击 **`③ 安装开机自动连（需管理员）.cmd`**，弹窗点「是」。

## 四、界面三个分页分别是什么

### 「状态」页
- 上面大字：现在**连上了没有**（绿=已联网，红=没联网）
- 下面一行：你的 IP、以及"凭什么判断连上了"
- 按钮：**立即连接** / **断开** / **立即检查** / **保存设置** / **导出设置…** / **导入设置…** / **打开日志** / **检查更新**
- ☑ **登录后自动打开** —— 勾上后开机自动把这个程序挂到后台（不弹窗）
- 最下面是**运行日志**，出问题时看这里

### 「校园网」页
- **接入方式**：有线 / 无线 / 两者都要
- **有线怎么认证**：7 种方式可多选（见第五节）
- **手动切换网络**：直接选"用校园网 / 用某个无线 / 全部断开"（见第七节）
- **连上校园网后自动关闭的代理/VPN**：代理软件名单 + 「断开后如果一直没在用代理就自动把校园网连回来」
- **无线策略**：把所有无线改成手动连接（防止自动连到别的网）
- **系统级守护**：安装/卸载"开机、锁屏自动连"（见第十一节）

### 「翻墙模式」页
- 开关：启用翻墙模式
- **什么时候翻墙**：只在没连校园网时（推荐）/ 任何时候
- ☑ **浏览器一打开就翻墙**（不靠窗口标题判断，最可靠）
- **翻墙客户端**：勾选允许使用的客户端（☑/☐），列表顺序 = 尝试顺序
- **触发程序**：打开哪些程序才翻墙
- **目标地区关键词** / **浏览器标题关键词**：挑节点、判断网页要不要翻墙

## 五、有线怎么认证（7 种，可多选）

不知道自己属于哪种，先看这张表：

| 你的情况 | 勾哪个 |
| --- | --- |
| 网络里有个「宽带连接」，点它要输账号密码 | **PPPoE 拨号** |
| 插上网线就有 IP，打开网页直接能上 | **自动获取 IP（DHCP）** |
| 插上网线后跳出一个网页要你登录 | **DHCP + Web 门户认证** |
| 学校给了固定的 IP / 网关 / DNS | **静态 IP** |
| 必须开学校发的认证软件才能上网 | **学校专用客户端** |
| 插上网线提示"正在验证身份" | **有线 802.1X** |
| 网线插着但老是连不上，拔插一下就好 | **先重启网卡** |
| 完全不确定 | **PPPoE 拨号 + 自动获取 IP 都勾上**，程序会自己按顺序试 |

点右边的「**有线详细设置…**」可以填细节（用哪块网卡、静态 IP 参数、学校客户端路径等）。
**不知道填什么就留空**，程序会自动选。

## 六、Web 门户认证（插上网线/连上 WiFi 后弹登录页的那种）

很多学校是"连上网了，但打开任何网页都跳到登录页，输学号密码才放行"。
这种就叫**门户认证**，程序能自动帮你过。

**怎么配**：点「**网页（门户）认证设置…**」按钮：

1. **厂商预设**：下拉选你们学校的牌子（深信服 / 锐捷 / Dr.COM / H3C），它会自动填好常用的地址和字段名
2. 填上你的门户账号密码（不填就用校园网账号密码）
3. 点「**测试网页认证**」—— 不用等掉线，它会真的试一次，过程和结果写在「状态」页的日志里

三种登录方式：
- **自动**（先试这个）：自动打开登录页、找到表单、把账号密码填进去、提交
- **按模板提交**：你自己填请求地址和内容（知道学校接口时最准）
- **执行命令**：学校给了脚本/命令行工具时最省事

> **各校字段名可能不一样**。最稳的办法：先在浏览器手动登录一次 →
> 按 `F12` → Network → 找到那条登录请求 → 照抄地址和内容（详见 `docs/WIRED.md`）。

**注意**：门户认证是**有线和无线共用**的 ——
也就是说，你用学校 WiFi 连上后上不了网，程序也会自动帮你过门户 ✓

## 七、手动切换网络

「校园网」页有「手动切换网络」，想用哪个网络点一下就切：

| 选择 | 效果 |
| --- | --- |
| **校园网（有线拨号）** | 取消暂停，守护重新启用网线并拨号 |
| **无线：<某个 Wi-Fi>** | 暂停自动拨号 + 断开校园网 + 连上这个 Wi-Fi |
| **全部断开** | 断开校园网并暂停自动拨号（手机热点那些不归它管，照常用） |

**手动选择优先**：你切走之后，它**不会**再自己把校园网拨回来，直到你切回「校园网」为止。

## 八、「断开」和「立即连接」

- **「断开」** = 断开校园网 + 暂停自动拨号（直到你点「立即连接」）
  - 只影响校园网那根线，**手机热点 / 无线照常可用**
  - 为什么需要它：校园网这个拨号连接**不属于普通可枚举的连接**，
    直接命令断开只会"返回成功但不断开"，所以程序会在必要时**暂时禁用一下有线网卡** ——
    这才是它能真正断开的原因（实测有效）
- **「立即连接」** = 重新启用网线 + 自动拨号 + 取消暂停

**还有三个贴心设计**：
- **开机照常连**：就算你上次断了没连回来，重启电脑后开机/锁屏照样自动连校园网
- **没翻墙就自动连回来**（可选，在「校园网」页勾）：
  你为了翻墙而断开校园网 → 翻完墙 / 没在翻墙 → 它自动把校园网连回来，你不用管。
  判定"在翻墙"看两个信号：翻墙标记 + 代理软件进程，所以很准。
- **跟着 VPN 走**（推荐，在「校园网」页勾）—— 一个开关保证你**随时都有网**：

  | 你做的事 | 程序自动做的事 |
  | --- | --- |
  | 打开浏览器 / Telegram | 先确认有可用的替代网络 → **断开校园网** → **再**开代理挑节点 |
  | 代理正在跑 | 保持校园网断开 + **自动连上你填的那个无线**（手机热点）→ 随时有网 |
  | **你一关掉 VPN** | **10 秒内**切回校园网 |

  在「翻墙时连接」后面填**手机热点的名字**（比如 `iPhone`）。
  下拉框里既能选"以前连过的无线"，也能选"现在就能扫到的无线"。

  **热点一开就自动连（默认开）** —— 这一条就是"我不想动手"的答案：

  | 情况 | 程序行为 |
  | --- | --- |
  | 你打开手机热点 | 程序**自己**把它连上（不用你去 Windows 的 Wi-Fi 列表里点） |
  | 热点要出现在范围内才行 | 手机上把「设置 → 个人热点」页面开着几秒，让热点广播出来 |
  | 顺手还会把该热点改成**自动连接** | 这样即使程序没开，Windows 自己也会连它 |
  | 热点名填错 / 手机热点名被改过 | 日志和 `--selftest` 会列出"现在扫到的无线"，照着改一下就对了 |

  > 以前这里有个自相矛盾的 bug：程序一边要"自动连热点"，一边又被
  > 「无线策略 → 把所有无线改成手动连接」把**热点也改成了手动**
  > —— 结果 Windows 永远不会自己连，只能你手动切。
  > **v1.11.2 起**：手动策略会自动放过"你指定的热点"和"校园网自己用的无线"。

  **安全闸门（默认开，强烈建议别关）**：
  打开浏览器时，程序会**先确认"有别的能上网的路"**，确认到了才敢断校园网：

  | 检查结果 | 程序行为 |
  | --- | --- |
  | 手机热点已连上且**真能上网** | 才断开校园网 → 自动开翻墙 |
  | 热点没连 | **自己连**（每 8 秒重试，最多等 60 秒）；连上并能上网才继续，否则**什么都不做** |
  | 连了热点但手机没开流量 | 判定不可用 → **校园网保持连接、翻墙也不开** |
  | 只有虚拟网卡（Hyper-V / WSL / VMware）有 IP | 判定不可用（它们出不去） |

  > 判断方式是**真的从那张网卡发一个 TCP 包出去**（热点则直接问手机网关），
  > 所以"连上了但没网"这种假信号不会被误判。
  > 一句话：**热点没准备好，它绝不动你的校园网。**

  > 「跟着 VPN 走」和上面的「没翻墙就自动连回来」作用重叠，
  > **建议只开一个**（开「跟着 VPN 走」就把它关掉），免得两套逻辑互相抢。

## 九、翻墙模式（这个是最"聪明"的功能）

**干什么**：你打开需要的程序时，它自动：开代理客户端 → 列出所有节点 → **筛出目标地区的节点**
→ **逐个真实测延迟** → 切到最快能用的那个 → 把系统代理指过去。

**什么时候翻墙**（「翻墙模式」页最上面选）：
- **只在没连校园网时**（推荐，默认）—— 连着校园网**绝不翻墙**
- **任何时候** —— 连着校园网也翻墙（校园网认证完成后才开代理）

**触发程序**：打开这些程序才翻墙。默认是 Telegram、Codex、Chrome。
- 非浏览器程序：**看进程名**，程序一启动就触发
- 浏览器（Chrome/Edge）：两种判断方式
  - 默认：看**窗口标题**里有没有关键词（默认含 chatgpt、google、youtube、twitter…）
  - 勾上「**浏览器一打开就翻墙**」：只看进程在不在 —— **最可靠**，
    不受标题是中文、报错页、新标签页影响

**翻墙客户端可勾选**：程序内置 6 个常见客户端（E-IX、魔戒、FlClash、FlyingBird、万达云、Clash Verge），
每个都是 ☑ 允许使用 / ☐ 不参与，**列表顺序 = 尝试顺序**。
- 例如只勾 **E-IX**，它就只试 E-IX，不会退到别的客户端
- 每行后面会显示「已装 / 未装」
- 有「**只留勾选的**」按钮，一键把勾选项排到最前

**怎么加新的客户端**：见 `docs/CLIENTS.md`。

> 小知识：多数 mihomo/Clash 系客户端可以直接用**自带内核 + 它自己的配置**启动，
> 不用开它的界面、也不用管理员权限。程序优先走这条路。

## 十、连上校园网时自动关掉代理/VPN

**为什么需要**：很多校园网在代理开着时拨不上号，或者认证会失败。

- 「校园网」页可以配**要关掉的程序名单**（默认内置了常见代理客户端）
- 触发时机有两个：**拨号前先关一次**、**连上校园网后再复查一次**
- 关闭方式"先礼后兵"：先礼貌关闭（让客户端有机会自己还原系统代理）→ 还活着的强制结束
  → 最后清理残留的系统代理设置
- 「**用内置名单**」按钮可以一键恢复默认名单

> 也和翻墙模式联动：**翻墙模式正在用代理时，它不会去关那个代理**（否则刚开起来就被杀掉）。

## 十一、开机 / 锁屏也能连（系统级守护）

- 双击 `③ 安装开机自动连（需管理员）.cmd` → 弹窗点「是」
- 装好后它会做一个计划任务，以 **SYSTEM** 身份常驻：
  **开机、锁屏、甚至你还没登录进桌面的时候都在工作**
- 每 5 分钟会检查一次自己还在不在，挂了自动拉起来
- 不想用了：双击 `④ 卸载开机自动连.cmd`

> 为什么必须以 SYSTEM 跑：PPPoE 拨号是**整台机器**的资源 ——
> 只在你的登录会话里拨号，一锁屏/切换用户就断了。

## 十二、其它小功能

| 功能 | 说明 |
| --- | --- |
| **功能开关** | 「校园网」页有一组**总开关**，每个自动行为都能单独关掉：断线自动重拨、拨号/接入前先关代理和 VPN、程序更新后自动重启、点关闭只是收进托盘、同一时间只允许开一个程序。还可以调**检测间隔**（默认 **10 秒**，越小越灵敏 —— 没连 VPN 时断线能更快恢复） |
| **无线策略** | 把所有已保存的无线改成"手动连接"（或直接禁用无线网卡），防止它自动连到别的网络 |
| **自动更新** | 程序文件更新后，界面程序会**检测到并自动重启成新版本**（窗口收回托盘），不用你手动重开 |
| **单实例保护** | 重复点快捷方式不会再开出第二个程序；已有实例时提示你"看右下角托盘" |
| **托盘** | 点右上角 ✕ **只是把窗口收起来**，程序继续在后台跑；双击托盘图标恢复窗口，右键托盘可退出 |
| **导出/导入设置** | 「状态」页一键把设置存成文件，换电脑或分享给同学用（密码是本机加密的密文，换机要重填） |
| **检查更新** | 「状态」页按钮，查 GitHub 上有没有新版本 |
| **日志** | 「状态」页直接看，或点「打开日志」；也写在 `%LOCALAPPDATA%\CampusNetAssistant\运行日志.txt` |

## 十三、命令行功能（会用的人才需要）

```bat
python -m campusnet                  :: 打开图形界面
python -m campusnet --selftest       :: 环境自检（网卡、认证方式、链路、客户端、守护），排查问题首选
python -m campusnet --scan           :: 扫描本机：拨号连接名、无线配置、已装代理客户端
python -m campusnet --install-boot   :: 安装开机/锁屏守护（需管理员）
python -m campusnet --uninstall-boot :: 卸载
python -m campusnet --set-account 学号 密码
python -m campusnet --boot           :: 系统级守护本体（由计划任务调用，一般不用手敲）
python scripts\feature_check.py      :: 全功能检查（88 项，把每个功能真跑一遍，不修改你的设置）
```

## 十四、出问题了怎么办

**第一步永远是**：双击 `② 自检（出问题先跑这个）.cmd`，把窗口内容截图发给懂的人。
它会告诉你：网卡有没有、认证方式是什么、校园网连没连、代理客户端装没装、守护在不在跑。

常见情况：

| 现象 | 怎么办 |
| --- | --- |
| 一直显示"未联网" | 先跑自检看「有线链路」；确认账号密码没错、网线插好 |
| 拨号报 **691** | 账号或密码错、欠费、同时在线设备超了 |
| 拨号报 **678** | 网线/墙上端口问题 |
| 拨号报 **651** | 网线没插好或网卡驱动异常 |
| 拨号报 **756** | "已经有一个拨号在进行中" —— 程序会自动重启服务清掉，等一下即可 |
| 门户认证不成功 | 改用"按模板提交"，按第六节的方法抓一次真实请求 |
| 打开浏览器没翻墙 | 确认程序在托盘里跑着；勾上「浏览器一打开就翻墙」；确认「什么时候翻墙」选对了 |
| 翻墙了但 Google 还是打不开 | 看「状态」页日志：是不是节点不行？把魔戒也勾上（它能自动测速挑节点） |
| 关不掉校园网 | 用「断开」按钮（它会请求守护执行，守护有权限）；直接按「立即连接」恢复 |
| **校园网怎么都连不上，报 756「已经有一个拨号连接在进行中」或 651「网卡报错」** | 多半是**有线网卡处于禁用状态**（程序为"断开"而禁用它之后没恢复回来）。程序会自动恢复（15 秒内）；你也可以自己来：**控制面板 → 网络连接 → 右键「以太网」→ 启用**，然后点「立即连接」。**如果手动启用了还是 756**：以管理员身份在「命令提示符」里跑 `net stop RasMan` 再 `net start RasMan` 即可清掉卡住的拨号状态 |
| 想彻底退出程序 | 右键右下角托盘图标 → **退出程序**（点 ✕ 只是收起来） |

## 十五、安全与隐私

- **所有事情都在你自己电脑上完成**，不往任何服务器上传数据
- 密码用 Windows 自带的加密功能（DPAPI）存在本机，**不存明文**、日志里也不打印
- 换电脑/换 Windows 账户后，密码要重新填一次（这是加密机制决定的）
- 卸载：删掉程序文件夹即可；如果装过"开机自动连"，先双击 `④ 卸载开机自动连.cmd`

## 十六、三个典型用法（可以照抄）

### 场景 1：宿舍网口 + 天天要翻墙
1. 校园网页：接入方式=**有线**，勾 **PPPoE 拨号**，填账号密码，保存
2. 勾上「连上校园网后自动关闭代理/VPN」
3. 翻墙模式页：勾上启用，选「**只在没连校园网时**」，客户端只勾 **E-IX**，
   触发程序加 Chrome，勾上「**浏览器一打开就翻墙**」
4. 双击 `③ 安装开机自动连` → 点「是」

→ 结果：开机自动连校园网；连着校园网绝不翻墙；切到手机热点后一开浏览器就翻墙。

### 场景 2：只想让校园网一直在，别的一概不管
1. 校园网页：接入方式、账号密码填好，保存
2. 无线策略选「**把所有无线改成手动连接**」（防止自动连到别的网）
3. 双击 `③ 安装开机自动连` → 点「是」

### 场景 3：要在校园网和手机热点之间来回切
1. 「校园网」页最下面的「**手动切换网络**」：
   - 想用校园网 → 选「校园网（有线拨号）」→ 点「切换到这个网络」
   - 想用热点 → 选「全部断开」→ 切换（校园网断开，热点不受影响）
2. 如果勾了「断开后如果一直没在用代理就自动把校园网连回来」：
   切到"全部断开"也不会被自动连回（**手动选择优先**）
